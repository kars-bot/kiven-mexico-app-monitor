# 墨西哥应用情报 · Kiven

固定监控页面：https://kars-bot.github.io/kiven-mexico-app-monitor/

监控 18 个墨西哥 Google Play 应用。中文汇总，评论及开发者回复保留西语原文。支持完整标题、应用身份、采集批次、星级、主题、关键词筛选；支持历史批次及 CSV 导出，筛选状态可以随链接分享。

GitHub Actions 每天北京时间 11:30（UTC 03:30）计划触发采集，完成后发布。GitHub 定时任务可能排队延迟，页面显示实际采集时间。网页流程可在电脑关闭时运行；原有本机 Activepieces 与 Excel 任务继续保留，采集时间及样本可能与网页流程不同。

初始导入两轮历史数据：3,491 条采样记录，按应用 ID 与评论 ID 去重后 2,521 条。最新初始批次为 2026-10-21 11:30（北京时间）。之后每轮数据存于 history，网页可切换查看。首次采到不等于过去 24 小时新发布；低分仅为样本中的 1–2 星；主题按关键词标记，可重叠，未翻译或判定事实。

seed.zip 包含可审查的网页源代码、构建产物、采集脚本及公开初始数据，不包含本机密钥、账号凭据、原始评论作者信息或本机路径配置。每天运行时先展开，再叠加 history 中的最新状态和历史快照，采集成功后更新 history 并发布站点。全部采集失败时不覆盖上一成功页面。

仓库不需要自定义账号密钥，工作流使用 GitHub 自动提供的仓库令牌。手动更新：Actions → 每日应用监控与发布 → Run workflow → 勾选立即采集。
